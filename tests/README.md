## Chạy

- Local: `pnpm db:test:up` một lần (container `postgres-test`, cổng 5436, tmpfs — tắt là mất sạch), rồi
  `pnpm test`.
- CI: job `test` trong `.github/workflows/ci.yml` (Postgres là service của job), chạy thêm `pnpm db:drift`.
- `tests/db-global-setup.ts` áp migration bằng `migrate deploy` (đúng các file SQL viết tay, không `db push`)
  lên DB mẫu `ghim_test`, rồi nhân bản một DB cho mỗi worker và xoá chúng khi lượt chạy xong. Tên DB mang mã
  lượt chạy, nên hai lượt chạy cùng lúc không giẫm nhau.
- `tests/db-worker-setup.ts` xoá sạch dữ liệu đầu mỗi file; file cần DB trống ở từng ca thì tự thêm
  `beforeEach(truncateAll)`.
- DB phải tên `…_test` — setup và `env.ts` từ chối DB khác.
- DB mẫu lệch migration (vd vừa đổi nhánh): `docker compose rm -sf postgres-test && pnpm db:test:up`.

Không có repository giả. Chỉ việc nền (`tests/fakes/jobs.fake.ts`), mailer và đồng hồ là giả: đó là thứ test
cần tự điều khiển, không phải thứ cần kiểm.
